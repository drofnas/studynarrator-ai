# Security Policy

## Supported versions

Before the first published release, security reports are evaluated against the
current `main` branch. After releases begin, only the latest published release is
supported.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability report form](https://github.com/drofnas/studynarrator-ai/security/advisories/new).

Include the affected version or commit, the distribution you ran (Docker Web,
source Web, or source Electron), operating system and architecture, reproduction
steps, and the expected and observed behavior.

Do not include study scripts, project names, private endpoints, access tokens,
credentials, or user data. Replace sensitive values with neutral placeholders and
provide only the minimum reproduction needed to explain the issue.

The project does not promise a response or remediation deadline.
