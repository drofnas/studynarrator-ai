# Application overhaul

Mode: Operate. Scope: every React surface shared by Web and Electron.
User confirmed: personal study, efficient authoring, preserve every capability,
code-first; visual decisions delegated to the agent.

## Grounded directions

1. Reference manager: a searchable project library and a focused document pane.
2. Recording console: stable transport and voice controls surrounding the script.
3. University course timetable: aligned task lanes and compact state labels.
4. Field notebook: continuous writing surface and a secondary annotation margin.
5. Technical manual workspace: clear navigation, document-sized type, consistent
   toolbars, and an unobstructed reading and editing canvas.
6. Transit wayfinding: explicit workflow destinations and unambiguous state signs.
7. Language flashcards: passage-focused practice with adjacent voice controls.

The script assigned direction 5, seed bcb72c8c. User delegated the choice.
The category rut is a decorative audio dashboard; its predictable opposite is a
retro recording desk. Neither is the chosen structure.

## Challenger judgments

All six were translated to the real script/voice/render workflow, then judged on
personal-study identification and product clarity.

- Variable font specimen: declined on both; huge specimens obscure writing.
  Raise: stronger distinction between editable content and supporting controls.
- Seven-segment instruments: declined on both; digits cannot lead a text workflow.
  Raise: keep status and time readouts stable while work changes.
- Generative identity: declined on both; reseeding fights a learned workspace.
  Raise: make the component system coherent across every screen.
- Character catalog: declined on both; fictional characters misrepresent voices.
  Raise: scan a real project roster without opening each project.
- Iridescent cloud edge: declined on both; observational navigation obscures tasks.
  Raise: reserve color for selection and meaningful state.
- Transforming cape: declined on both; spatial gestures add cognitive load.
  Raise: responsive changes must preserve the structure of the current task.

## Direction contract

THESIS: A focused study workspace: find a project, write, then listen. Replace the
oversized industrial headings and boxed instrument panels with clear hierarchy.

OWN-WORLD: Restrained iris actions, graphite navigation, cool white working
surfaces, quiet gray dividers, a system sans, and precise shared control shapes.
The author studies at a desk in ordinary daylight; light content supports long
reading sessions, while the darker navigation rail stays peripheral.

STORY: Projects are the main destination. Tools support a visible script-to-audio
workflow; setup, state, and recovery explain what to do next.

FIRST VIEWPORT: A compact left navigation rail and a broad, light project library.
A 32px heading, brief description, and New project action lead into search and
scannable rows. The project opens into compact identity fields and sticky task
tabs, with the script taking most of the viewport. Signature interaction: the
active tab stays in reach while a long script scrolls, and render activity stays
available in the navigation. Mobile uses the existing keyboard-safe drawer.

same controls, type scale, and state vocabulary through setup, prompt kit, audio,
settings, diagnostics, and recovery. Risk: restrained utility requires disciplined
spacing and real task improvements to avoid feeling generic.
